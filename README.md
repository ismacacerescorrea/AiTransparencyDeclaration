# AI Transparency Declaration (AITD) Plugin

Módulo para integrar el Modelo de Declaración de Transparencia sobre el Uso de Inteligencia Artificial (AITD) en las plataformas de Public Knowledge Project (PKP): **Open Journal Systems (OJS), Open Monograph Press (OMP) y Open Preprint Systems (OPS)**.

El proyecto busca incorporar declaraciones estructuradas sobre el uso de inteligencia artificial en los procesos editoriales de revistas científicas, publicaciones monográficas y servidores de preprints.

## Plataformas y compatibilidad

| Plataforma | Estado | Versiones probadas |
|---|---|---|
| Open Journal Systems (OJS) | Disponible | 3.3.0-22, 3.4.0-10 y 3.5.0-5 |
| Open Preprint Systems (OPS) | Disponible | 3.5.0-5 |
| Open Monograph Press (OMP) | Desarrollo previsto | Pendiente |

Las implementaciones se distribuyen en paquetes independientes. Las versiones señaladas corresponden exclusivamente a distribuciones en las que se han realizado pruebas y no implican compatibilidad general con todas las versiones de una misma familia.

## Original model and attribution / Modelo original y reconocimiento

El módulo adapta el **AI Transparency Declaration (AITD) Model v1.1**, creado por Sergio Santamarina y Carlos Authier, con contribuciones de Aamir Sohail.

Modelo original: https://doi.org/10.5281/zenodo.18601557

La adaptación tecnológica para las plataformas PKP es desarrollada por **Ismael Cáceres-Correa**, de **Sociedad Realidad e Historia**.
